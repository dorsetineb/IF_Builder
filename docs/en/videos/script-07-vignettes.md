# Video Script #07 — Vignettes

**Title:** Creating Cinematic Screens with Vignettes  
**Estimated duration:** 3–4 minutes  
**Series:** IF Builder Tutorials

---

## 🎙️ Script

### [00:00 – 00:25] WHAT ARE VIGNETTES

> *[Screen: Opening vignette running — text appearing with typewriter effect over an image]*

**Narrator:**
"Vignettes are cinematic screens — moments where the story pauses interaction and presents something dramatically. An opening, a revelation, an ending."

"In IF Builder, there are three types: Opening, Transition, and Conclusion."

### [00:25 – 01:20] CREATE OPENING VIGNETTE

> *[Action: Narrative list → Create Chapter or Branch → Create Chapter]*

**Narrator:**
"To create a vignette, I click the add button in the narrative list and choose 'Create Chapter'."

"Type: Opening. This makes this screen appear before any branch."

> *[Action: fill Title = "The Lighthouse Key", text, background image]*

"The title here is the game's name. For the text, I write something atmospheric — two or three short sentences that hook the reader before the story begins."

### [01:20 – 02:00] ANIMATION AND EFFECT

> *[Action: select Typewriter animation, speed 3]*

**Narrator:**
"In the animation section, I select Typewriter mode — the text appears letter by letter, as if being typed live. Very effective for building tension."

> *[Action: select visual effect "Rain"]*

"And for the visual effect, I choose 'Rain' — an animated overlay that falls over the image. Perfect for our story's atmosphere."

### [02:00 – 02:40] CREATE CONCLUSION

> *[Action: create new vignette — Conclusion type]*

**Narrator:**
"Now I create the Conclusion Vignette — the game's ending screen. Type: Conclusion."

"Different title, different hopeful text this time. Different image — light and ocean at dawn."

### [02:40 – 03:10] CONNECT TO FLOW

> *[Action: Opening → set Next Scene = Lighthouse Entrance]*

**Narrator:**
"To connect the Opening to the story flow, I set which branch appears when the player clicks the button."

> *[Action: go to Lantern Room → Properties → Conclusion Chapter → select vignette]*

"And for the Conclusion, I go to 'Lantern Room' and select the conclusion vignette as this branch's ending screen."

### [03:10 – 03:30] CTA

**Narrator:**
"Your fiction now has an opening, interaction, and conclusion. In the final video of this series, we'll export the project and learn how to share it."

"See you there."
