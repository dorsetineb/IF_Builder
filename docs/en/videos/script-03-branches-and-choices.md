# Video Script #03 — Branches and Choices

**Title:** Creating Branches and Writing your Narrative  
**Estimated duration:** 4–5 minutes  
**Series:** IF Builder Tutorials

---

## 🎙️ Script

### [00:00 – 00:20] WHAT ARE BRANCHES

> *[Screen: Connections map with several connected branches]*

**Narrator:**
"In IF Builder, your story is divided into Branches — each one is a scene, a location, or a moment in the narrative. Think of them like pages of a book, but connected."

### [00:20 – 01:30] CREATE THE FIRST BRANCH

> *[Action: click Narrative in sidebar → click the initial branch]*

**Narrator:**
"In the narrative panel, we already have an automatically created branch. I'll click to edit it."

"In the title field, I'll name this branch 'Lighthouse Entrance'."

"Now the description — this is the text the player reads when entering the scene."

> *[Action: type the scene description with `<rusty key>` and `<iron staircase>`]*

### [01:30 – 02:15] INTERACTIVE TEXT

> *[Action: show `<rusty key>` in the text]*

**Narrator:**
"Here's a really interesting feature. If I put a word between angle brackets — like this: `<rusty key>` — it will appear highlighted in the game."

"The player can click on it to fill the command field automatically, or type verbs like 'examine key' or 'take key'. It's a way to guide the player without removing the feeling of exploration."

### [02:15 – 03:00] MORE BRANCHES

> *[Action: create Dark Corridor, Lantern Room, Defeat branches]*

**Narrator:**
"To create more branches, I click the add button in the narrative list. I'll create the Dark Corridor, the Lantern Room — marked as the positive ending — and the Defeat branch."

### [03:00 – 03:45] CONNECTIONS MAP

> *[Action: click "Branch Map" in sidebar]*

**Narrator:**
"I can see all branches graphically in the Connections Map. Right now they're disconnected — connections appear when we set up interactions in the next videos."

### [03:45 – 04:10] IMAGE AND MUSIC

> *[Action: load background image in multimedia section]*

**Narrator:**
"Each branch can have a background image and music. It's optional, but it makes a huge difference in atmosphere."

### [04:10 – 04:30] CTA

**Narrator:**
"Branches created. In the next video, we'll add objects — like the key — and set up the game's inventory. See you there."
