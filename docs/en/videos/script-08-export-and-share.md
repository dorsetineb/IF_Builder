# Video Script #08 — Export and Share

**Title:** Exporting and Sharing your Interactive Fiction  
**Estimated duration:** 3–4 minutes  
**Series:** IF Builder Tutorials

---

## 🎙️ Script

### [00:00 – 00:20] RECAP

> *[Screen: Editor with complete project — branch list, map]*

**Narrator:**
"Our fiction is complete: branches written, objects created, interactions configured, Trackers working, opening and conclusion vignettes ready. Time to export."

### [00:20 – 01:00] FULL PREVIEW TEST

> *[Action: click Preview in header]*

**Narrator:**
"Before exporting, I do a full test. I click Preview in the header — this opens the game from beginning to end, starting with the opening vignette."

> *[Screen: Play the fiction from start to finish — show victory and defeat paths]*

"I'll go through all paths: the victory path and the defeat path via the Health Tracker."

"Everything works. Ready to export."

### [01:00 – 01:45] SAVE THE .ZIP

> *[Action: click the floppy disk icon in the header]*

**Narrator:**
"In the header, I click the Save button — the floppy disk icon."

> *[Action: type "the-lighthouse-key" and confirm]*

"I type the file name: 'the-lighthouse-key'. Confirm."

> *[Screen: .zip download starts]*

"The browser downloads the zip file. This file contains the complete game — HTML, data, images, audio, game engine."

"Remember: the editor does not auto-save. Always save when you make important changes."

### [01:45 – 02:30] PLAY OFFLINE

> *[Action: open file explorer → find zip → extract]*

**Narrator:**
"Now I'll extract the file. Right-click — extract here."

> *[Action: open extracted folder → click index.html]*

"Inside the folder, I open the index.html file directly in the browser."

> *[Screen: Game opens — opening vignette appears]*

"And here it is — the game running completely offline. No internet. No server. No editor."

"Anyone can play this on any computer."

### [02:30 – 03:00] RESUME EDITING

> *[Action: IF Builder → Load → select the .zip]*

**Narrator:**
"And if you want to keep editing later? Simple: open IF Builder, click Load, select the zip."

"The editor restores everything — exactly as it was."

"This also means you can share the zip with another IF Builder author. They can import it, see how you built it, and even make a remix."

### [03:00 – 03:30] SHARING OPTIONS

**Narrator:**
"Ways to share your fiction: send the zip via email or message. Publish on itch.io — a free platform for games that accepts HTML projects. Or just save it to a flash drive and give it as a gift."

### [03:30 – 03:50] SERIES FINALE CTA

> *[Screen: IF Builder logo + grid of all 8 videos in the series]*

**Narrator:**
"And we've reached the end of this series. You've learned how to create a complete interactive fiction from scratch with IF Builder."

"If you create something, share it! I'd love to see what you built."

"IF Builder is free at ifbuildr.com. If it's been useful to you, consider supporting the project."

"Thank you, and until the next story."
