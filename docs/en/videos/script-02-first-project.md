# Video Script #02 — Creating your First Project

**Title:** Creating your first project in IF Builder  
**Estimated duration:** 3–4 minutes  
**Series:** IF Builder Tutorials

---

## 🎙️ Script

---

### [00:00 – 00:15] RECAP

> *[Screen: IF Builder welcome screen with "Create a fiction" button highlighted]*

**Narrator:**
"In the previous video, you saw what IF Builder is. Now let's start from scratch — creating your first project."

---

### [00:15 – 01:00] CREATE FICTION

> *[Action: click "Create a fiction" → "New Fiction" window opens]*

**Narrator:**
"On the editor's home screen, click 'Create a fiction'. A window with three tabs will appear — this is where you configure everything before you start writing."

---

### [01:00 – 02:00] OPENING TAB

> *[Action: fill in the Opening tab fields]*

**Narrator:**
"On the first tab, you configure your fiction's opening. The title is the game's name — it will appear on the start screen for the player."

> *[Type: "The Lighthouse Key"]*

"The description is a brief summary. The button text is what the player clicks to begin."

"You can also add a background image — it will appear on the game's opening screen."

---

### [02:00 – 02:45] MECHANICS TAB

> *[Action: click "Mechanics" tab]*

**Narrator:**
"On the Mechanics tab, choose the interaction style. Parser mode is classic: the player types verbs like 'take key' or 'open door'."

> *[Action: select Parser]*

"Choice mode shows predefined buttons — simpler, more accessible."

"For this project, we'll use Parser. Below, I'll enable Inventory and Trackers."

> *[Action: enable Inventory and Trackers]*

---

### [02:45 – 03:15] VISUAL STYLE TAB

> *[Action: click "Visual Style" tab]*

**Narrator:**
"On the last tab, define your game's visual style. There are several predefined themes — I'll choose 'Midnight', which has a dark, mysterious look."

---

### [03:15 – 03:40] CREATE PROJECT

> *[Action: click "Create Project"]*

**Narrator:**
"Click Create Project. The editor opens with your fiction's initial structure — sidebar on the left, branch list in the center, branch editor on the right."

"Your project is created. Now it's time to write."

---

### [03:40 – 04:00] CTA

**Narrator:**
"In the next video, we'll create the first branches of the story and write the descriptions. See you there."

---
