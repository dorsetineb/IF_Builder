# Video Script #01 — Welcome to IF Builder

**Title:** What is IF Builder?  
**Estimated duration:** 2–3 minutes  
**Series:** IF Builder Tutorials

```
[00:00 – 00:20]  Hook / Opening
[00:20 – 01:00]  What is interactive fiction
[01:00 – 01:40]  What IF Builder solves

[02:20 – 02:40]  CTA and next videos
```

---

## 🎙️ Script

---

### [00:00 – 00:20] HOOK

> *[Screen: Interactive fiction game running in browser — typewriter effect, player types "take key"]*

**Narrator:**
"What if you could write a story where the reader decides what happens? Not a book, not a complex game — something in between."

---

### [00:20 – 01:00] WHAT IS INTERACTIVE FICTION

> *[Screen: Simple diagram showing branching narrative — a choice tree]*

**Narrator:**
"Interactive fiction is a text-based narrative where the reader participates. They can choose paths, collect objects, interact with the setting — and each decision changes the story."

"It's a tradition that goes back to the 70s, with games like Zork and text adventures. Today, authors around the world still create these stories."

---

### [01:00 – 01:40] WHAT IF BUILDER SOLVES

> *[Screen: IF Builder interface — clean and organized editor]*

**Narrator:**
"The problem is that creating interactive fiction always required technical knowledge. You needed to write code, learn specific languages, deal with complex files."

"IF Builder changes that. It's a visual editor where any writer can create branching stories without programming — and export a file that works in any browser."

---

### [01:40 – 02:20] QUICK DEMO

> *[Screen: IF Builder in action — 3 clicks: create branch, add object, preview]*

**Narrator:**
"You create branches — each one is a scene of the story. Write descriptions, add images and music, define what happens when the player interacts with objects."

"When you're done, export a zip file. The player extracts it, opens index.html, and plays right in the browser — no internet, no installation."

---

### [02:20 – 02:40] CTA

> *[Screen: IF Builder logo + URL ifbuildr.com]*

**Narrator:**
"In the next videos in this series, I'll show you step by step how to create your first interactive fiction with IF Builder."

"Visit ifbuildr.com — it's free — and see you in the next video."
