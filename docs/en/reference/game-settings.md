# Reference — Game Settings

**Game Settings** control the visual appearance, mechanics systems, and animations of the exported fiction. Changes made here affect the **final game** — not the editor.

---

## Access

Available in two places:
- **When creating a project**: "New Fiction" window → Mechanics and Visual Style tabs
- **After creation**: Sidebar → **"Interface"** (UIEditor / ThemeEditor)

---

## Branch Layout

| Field | Options |
|-------|---------|
| **Orientation** | Vertical / Horizontal |
| **Image Position** | Left, Right, Above, Below |
| **Image Frame** | None, Portal, Square, Rounded |

## Custom Colors

| Color | Affects |
|-------|---------|
| **Text** | Main narrative text color |
| **Titles and Highlights** | Branch titles and highlighted words |
| **Background** | Game background |
| **Focus Color** | Input borders, clickable text |
| **Action Button** | Main interaction button color |
| **System Buttons** | Inventory, Logbook, Trackers, etc. |

---

## Fonts and Text

| Field | Options |
|-------|---------|
| **Font Family** | Google Fonts list + special fonts |
| **Size** | Small, Medium, Large, Extra Large |

---

## Systems

| System | Description |
|--------|-------------|
| **Inventory** | Panel of items collected by the player |
| **Logbook** | Automatic log of actions and events |
| **Trackers** | Progress bars (health, coins...) |
| **Chance System** | Limited lives (legacy basic system) |
| **Fixed Verbs** | Always-visible command buttons |
| **Suggestions** | Verb hints available in the branch |
| **Retrospective** | Progress review panel |

---

## Animations

### Text Animations

| Field | Options |
|-------|---------|
| **Type** | `fade` / `typewriter` |
| **Speed** | 1 (very slow) to 10 (very fast) |
| **Reading Flow** | Continuous / Paused |

### Image Animations

| Field | Options |
|-------|---------|
| **Type** | `fade`, `slide-left`, `slide-right`, `slide-up`, `slide-down`, `zoom`, `blur`, `none` |
| **Speed** | 1–10 |
