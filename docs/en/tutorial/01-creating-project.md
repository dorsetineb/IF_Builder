# Module 01 — Creating your Project

**Tutorial: The Lighthouse Key**  
Estimated time: 5–8 minutes

---

## Goal of this module

In this module you will:
- Create a new project in IF Builder
- Configure the title, description and cover image
- Choose the interaction mode (Parser)
- Enable the systems we'll use (Inventory, Trackers)
- Configure the initial visual style

---

## Step 1 — Access the editor

After logging in at [ifbuildr.com](http://www.ifbuildr.com), you'll see the **welcome screen**. Click **"Create a fiction"**.

> 💡 If you already have a project open, go to the header and click the **New Project** icon (document with `+`).

---

## Step 2 — Configure the Opening

The **"New Fiction"** window opens with three tabs: **Opening**, **Mechanics**, and **Visual Style**.

On the **Opening** tab, fill in:

| Field | Value for this tutorial |
|-------|------------------------|
| **Title** | The Lighthouse Key |
| **Description** | A stormy night. An abandoned lighthouse. A key that shouldn't be here. |
| **Button Text** | Begin the adventure |
| **Background Image** | *(optional — use a dark lighthouse image or leave blank)* |

> 💡 The cover image appears on the game's start screen. Recommended: **1920×1080 pixels**.

---

## Step 3 — Configure Mechanics

Click the **Mechanics** tab.

**Interaction mode**: Select **Parser (Describe verbs)**  
The player will type actions like `take key` or `climb stairs`.

**Enabled systems**: Activate the following:

| System | Enable? | Reason |
|--------|---------|--------|
| ✅ Inventory | **Yes** | The player will collect the Rusty Key |
| ✅ Trackers | **Yes** | We'll create a Health Tracker |
| ⬜ Logbook | Optional | Automatically records player actions |
| ⬜ Chance System | No | We'll use Trackers instead |

---

## Step 4 — Configure Visual Style

Click the **Visual Style** tab.

For our mystery/horror fiction, we recommend:

**Branch Layout**:
- **Orientation**: Vertical
- **Image Position**: Above

**Predefined Themes**: Select **Midnight** (dark background, mysterious tone)

> 💡 You can change the theme at any time in **Game Settings** in the sidebar.

---

## Step 5 — Create the Project

Click **"Create Project"**. The editor will open with your fiction's initial structure.

You'll see:
- The **sidebar** on the left with editor modules
- The **narrative list** with an automatically created initial branch
- The **Branch Editor** on the right, ready for editing

---

## ✅ Module 01 Checklist

- [ ] Project created with the title "The Lighthouse Key"
- [ ] Parser mode selected
- [ ] Inventory and Trackers enabled
- [ ] "Midnight" visual theme applied
