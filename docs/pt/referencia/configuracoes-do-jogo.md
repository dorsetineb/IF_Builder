# Referência — Configurações do Jogo

As **Configurações do Jogo** controlam a aparência visual, os sistemas de mecânica e as animações da ficção exportada. As alterações feitas aqui afetam o **jogo final** — não o editor.

---

## Acesso

Disponível em dois locais:
- **Ao criar um projeto**: Janela "Nova Ficção" → abas Abertura, Mecânicas e Estilo Visual
- **Após criação**: Menu lateral esquerdo → páginas dedicadas **"Mecânicas"**, **"Estilo Visual"** e **"Rótulos"**

---

## Seção: Layout de Ramos

Define como imagem e texto são dispostos em cada cena.

| Campo | Opções |
|-------|--------|
| **Orientação** | Vertical / Horizontal |
| **Posição da Imagem** | Esquerda, Direita, Acima, Abaixo |
| **Quadro da Imagem** | Nenhum, Portal, Quadrado, Arredondado |

---

## Seção: Cores Customizadas

Ajuste fino das cores do jogo:

| Cor | Afeta |
|-----|-------|
| **Texto** | Cor principal do texto narrativo |
| **Títulos e Destaques** | Títulos de ramos e palavras em destaque |
| **Fundo** | Background do jogo |
| **Cor de Foco** | Bordas de input, textos clicáveis |
| **Botão de Ação** | Cor do botão principal de interação |
| **Botões do Sistema** | Inventário, Diário, Trackers, etc. |

---

## Seção: Fontes e Texto

| Campo | Opções |
|-------|--------|
| **Família de Fonte** | Lista de fontes Google Fonts + fontes especiais |
| **Tamanho** | Pequeno, Médio, Grande, Extra Grande |

---

## Seção: Sistemas

Habilite ou desabilite mecânicas do jogo:

| Sistema | Descrição |
|---------|-----------|
| **Inventário** | Painel de itens coletados pelo jogador |
| **Diário** | Registro automático das ações e eventos |
| **Trackers** | Barras de progresso (saúde, moeda...) |
| **Sistema de Chances** | Vidas limitadas (sistema básico legado) |
| **Verbos Fixos** | Botões de comando sempre visíveis |
| **Sugestões** | Dicas de verbos disponíveis no ramo |
| **Retrospectiva** | Painel de revisão de progresso |

---

## Seção: Animações

### Animações de Texto

| Campo | Opções |
|-------|--------|
| **Tipo** | `fade` / `typewriter` |
| **Velocidade** | 1 (muito lento) a 10 (muito rápido) |
| **Fluxo de Leitura** | Contínuo / Pausado |

### Animações de Imagem

| Campo | Opções |
|-------|--------|
| **Tipo** | `fade`, `slide-left`, `slide-right`, `slide-up`, `slide-down`, `zoom`, `blur`, `none` |
| **Velocidade** | 1–10 |

### Animações de Menu

| Campo | Opções |
|-------|--------|
| **Tipo** | `fade`, `slide`, `none` |
| **Som de Transição** | Upload de MP3 |
